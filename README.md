# Го — тренер для Android

Игра го для телефона: партии с ботом, учебные задачи по уровням и разбор ходов с объяснением,
почему ход хороший или плохой. Это Android-версия настольной программы «Го — тренер»
с теми же возможностями и на русском языке.

Всё работает на телефоне, без интернета. За сильного бота и анализ отвечает
[KataGo](https://github.com/lightvector/KataGo) (лицензия MIT): он собран под процессор телефона
и встроен в приложение вместе с быстрой нейросетью.

## Как установить

1. Откройте раздел [Releases](../../releases) и скачайте на телефон последний файл `GoTrainer-*.apk`.
2. Откройте скачанный файл. Если Android спросит, разрешите установку приложений из этого источника.
3. Новые версии ставятся поверх старой, решённые задачи и настройки сохраняются.

Нужен Android 8.0 или новее.

## Что умеет

- **Партия с ботом** на доске 9×9, 13×13 или 19×19, китайские или японские правила, коми и фора.
  Шесть уровней силы: от «Новичка» (встроенный бот, работает всегда) до «Профи».
- **Подсказка**: ИИ показывает три лучших хода и объясняет каждый.
- **Объяснить ход**: насколько ход хорош, сколько очков теряет, что было лучше и почему.
- **Разбор партии**: график шансов на победу и список ошибок; касание ошибки показывает позицию
  (зелёный кружок — лучший ход, красный — сыгранный, цифры — продолжение).
- **Карта территории** и **подсчёт очков** с автоматической отметкой мёртвых камней.
- **Курс задач** (35 задач в 13 уровнях) и **библиотека на 15 813 задач** с русскими условиями
  и комментариями; «Разбор с ИИ» объясняет любой ваш ход.
- **Импорт задач из SGF**: несколько файлов сразу или ZIP-архив со сборником (раздел «Мои сборники»).
- Открытие и сохранение партий в SGF (вместе с комментариями разбора).
- В «Настройках» можно скачать нейросети посильнее (b15, b20): они играют лучше, но думают дольше.

Как ставить камни: коснитесь пересечения, камень можно подвинуть пальцем и отпустить. На досках
13×13 и 19×19 по умолчанию ход подтверждается вторым касанием (меняется в «Настройках»).

## Как устроено

- `app/src/main/assets/www` — интерфейс и вся логика игры на JavaScript: правила (`board.js`),
  подсчёт (`scoring.js`), объяснения ходов (`explain.js`), задачи и импорт SGF, встроенный бот.
  Логика перенесена из настольной версии на Python и сверена с ней (`tools/parity`).
- `app/src/main/java/ru/gotrainer` — оболочка Android: окно WebView, запуск KataGo в режиме анализа,
  открытие и сохранение файлов, скачивание нейросетей.
- `katago/build-android.sh` — сборка KataGo (CPU, Eigen) через Android NDK для arm64-v8a,
  armeabi-v7a и x86_64.
- `.github/workflows/build.yml` — GitHub Actions собирает KataGo, скачивает нейросеть, собирает APK
  и публикует его в Releases при каждом изменении ветки `main`.

### Собрать самому

Нужны Android SDK, NDK, JDK 17, `libeigen3-dev` и `ninja`:

```bash
for abi in arm64-v8a armeabi-v7a x86_64; do katago/build-android.sh $abi out; \
  mkdir -p app/src/main/jniLibs/$abi; cp out/$abi/libkatago.so app/src/main/jniLibs/$abi/; done
mkdir -p app/src/main/assets/katago   # сюда положить нейросеть *.bin.gz
./gradlew assembleRelease
```

Ключ подписи `app/gotrainer.keystore` (пароль `gotrainer`) лежит в репозитории, чтобы любая сборка
устанавливалась поверх предыдущей. Для публикации в магазинах приложений замените его своим
через переменные `SIGNING_STORE`, `SIGNING_STORE_PASSWORD`, `SIGNING_KEY_ALIAS`, `SIGNING_KEY_PASSWORD`.
