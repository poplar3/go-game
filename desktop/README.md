# Го — тренер

Настольная игра го для Windows 11 (и Linux): партии с ботом, учебные задачи по уровням
и разбор ходов с объяснением, почему ход хороший или плохой.

Всё работает на вашем компьютере, без интернета и без платных запросов к облачному ИИ.
За бота и анализ отвечает [KataGo](https://github.com/lightvector/KataGo) — сильный открытый
движок го (лицензия MIT). Он скачивается один раз (около 120 МБ).

## Что умеет

- **Партия с ботом** на доске 9×9, 13×13 или 19×19. Правила подсчёта на выбор: китайские
  (по площади) или японские (по территории), коми и фора настраиваются. Шесть уровней силы бота:
  от «Новичка» (встроенный бот, работает даже без KataGo) до «Профи».
- **Подсказка**: ИИ показывает три лучших хода и объясняет каждый.
- **Объяснить ход**: разбор хода на доске: насколько он хорош, сколько очков теряет, что было лучше
  и почему. Например: «Почему это плохо: после этого хода погибает ваша группа из 6 камней в левом
  верхнем углу… Лучше было C3: спасает группу из атари…».
- **Разобрать партию**: ИИ проверяет все ходы, рисует график шансов на победу и составляет список
  ошибок. Щелчок по ошибке показывает позицию: зелёный кружок — лучший ход, красный — сыгранный,
  цифры — ожидаемое продолжение.
- **Карта территории**: кто владеет какой областью доски по оценке ИИ.
- **Подсчёт очков** в конце партии: ИИ сам отмечает мёртвые камни, их можно поправить щелчком.
- **Курс задач** — 35 задач в 13 уровнях, сгруппированных по этапам игры: основы, тактика, жизнь
  и смерть, форма, дебют, середина игры и ёсэ (конец игры). Темы: атари и захват, лестница и сеть,
  двойное атари и уттэгаэси, гонка за дамэ (семеай), ко и угрозы ко, фигуры глаз и ложные глаза,
  пословицы о форме, дебют на 9×9 и 19×19, режущие камни, границы и дамэ в конце партии.
  У каждой задачи есть блоки «Что изучаем» (концепция) и «Зачем это в партии», ссылка на книгу,
  по мотивам которой она составлена (Кано, Кагеяма, Дэвис, Тё Тикун, Отакэ, Ишида, Огава, Хантер,
  «Гокё Сюмё»), подсказка, решение, объяснение правильного хода и каждой типичной ошибки.
  Задачи из дебюта, середины игры и ёсэ проверены KataGo: правильными считаются ходы, которые
  ИИ оценивает почти как лучший, а у ошибок указана цена в очках. Кнопка «Разбор с ИИ» проверяет
  любой ваш вариант. Решённые задачи отмечаются галочкой.
- **Библиотека задач — 15 813 задач** из сборников Ultimate Go Problems (Тё Тикун, Саката Эйо,
  «Сюаньсюань Цицзин», Го Сэйгэн, серия Get Strong, AGA, китайский и корейский сборники) и курсов
  wbaduk. Задачи разложены по силе (25–16 кю, 15–10 кю, 9–4 кю, 3 кю – 2 дан, 3–5 дан,
  тематические сборники) и по темам: захват, жизнь и смерть, тесудзи, семеай, ёсэ, дебют, хэнма,
  дзёсэки и другие. У каждой темы и приёма есть русское объяснение «Что изучаем» и «Зачем это в
  партии». Условия задач и комментарии к ходам переведены на русский
  (с английского, японского, китайского и корейского), включая корейские и китайские пояснения,
  которые раньше не показывались. Названия книг и имена авторов оставлены как в оригинале.
  «Разбор с ИИ» объясняет любой ход по-русски. Разделы библиотеки раскрываются щелчком по треугольнику.
- **Импорт задач из SGF** (кнопка под списком задач или «Файл → Импорт задач из SGF…»): можно
  добавить отдельные файлы или целую папку со вложенными папками. Подходят любые сборники цумэго в формате SGF, например с nikoraido.ru или rusgolib.gofederation.ru.
  Они появятся в разделе «Мои сборники». Правильные варианты распознаются по пометкам RIGHT /
  Correct / «правильно» в комментариях, а если пометок нет, правильным считается первый вариант.
- Сохранение и открытие партий в формате SGF (вместе с комментариями разбора).

## Готовые сборки

Проще всего скачать готовую программу в разделе [Releases](https://github.com/poplar3/go-game/releases)
(выпуски с названием «Го — тренер для ПК»). Python для них не нужен.

| Система | Файл | Как запустить |
|---|---|---|
| Windows 10/11 | `GoTrainer-*-windows-x64.zip` | Распакуйте архив и запустите `GoTrainer\GoTrainer.exe` |
| Ubuntu 22.04+, Debian 12+, Mint 21+ | `gotrainer_*_amd64.deb` | `sudo apt install ./gotrainer_*_amd64.deb`, игра появится в меню «Игры», команда `gotrainer` |
| Любой Linux x86-64 | `GoTrainer-*-x86_64.AppImage` | `chmod +x GoTrainer-*.AppImage`, затем запустите файл |

Сборки делает GitHub Actions (`.github/workflows/desktop.yml`) при каждом изменении папки `desktop`
в ветке `main`; перед публикацией .deb и AppImage проверяются запуском на чистой Ubuntu 24.04.
KataGo в сборки не входит: его скачивает кнопка в «Настройках». Если папка программы закрыта
для записи (установка из .deb, AppImage, Program Files), KataGo сохраняется в папку настроек
пользователя: `~/.config/GoTrainer/katago` или `%APPDATA%\GoTrainer\katago`.

## Установка на Windows 11 из исходников

1. Установите Python 3.10 или новее: https://www.python.org/downloads/
   (при установке отметьте **Add python.exe to PATH**).
2. Скопируйте папку `go-game` к себе на компьютер.
3. Запустите `run_windows.bat`. В первый раз он сам создаст окружение и установит PySide6
   (несколько минут), дальше игра открывается сразу.
4. В игре откройте **Настройки → ИИ KataGo…** и нажмите **Скачать KataGo**.
   - «Процессор (CPU, AVX2)» — работает на любом современном компьютере;
   - «Видеокарта (OpenCL)» — в разы быстрее, если есть видеокарта с драйверами.

   Затем «Сохранить и перезапустить ИИ». Внизу окна появится «ИИ KataGo готов».

Без KataGo игра тоже работает: доступны встроенный бот «Новичок», задачи и тактические
объяснения ходов (атари, захват, лестница, глаза), но без оценки в очках.

### Собрать GoTrainer.exe

Чтобы получить программу, которой не нужен Python (например, для другого компьютера),
запустите `build_windows_exe.bat`. Готовая папка появится в `dist\GoTrainer`; если KataGo
уже скачан в папку `katago`, он скопируется рядом с exe.

## Как установить обновление

1. Закройте игру.
2. Скачайте новый архив `go-game.zip` и распакуйте его **поверх** старой папки `go-game`
   (на вопрос о замене файлов ответьте «Заменить все»). Папки `katago` (ИИ и нейросеть) и `.venv`
   (Python-окружение) в архиве нет, поэтому они останутся как были, и ничего не придётся
   скачивать заново.
3. Запустите `run_windows.bat` как обычно.

Отметки о решённых задачах и настройки хранятся отдельно от папки программы (в реестре Windows),
а импортированные сборники SGF — в `%APPDATA%\GoTrainer`, поэтому после обновления они сохранятся.
Если вы собирали `GoTrainer.exe`, после обновления запустите `build_windows_exe.bat` ещё раз.

## Linux из исходников

```bash
bash run_linux.sh
```

KataGo для Linux скачивается тем же меню «Настройки» (или командой
`python -m gogame.engine.download --variant cpu`).

### Собрать .deb и AppImage

На Ubuntu 22.04 (сборка на старой системе запускается и на новых):

```bash
sudo apt install python3-venv libgl1 libegl1 libxkbcommon-x11-0 libxcb-cursor0 libxcb-icccm4 \
     libxcb-image0 libxcb-keysyms1 libxcb-render-util0 libxcb-xkb1 libxcb-shape0 libxcb-randr0 \
     desktop-file-utils
packaging/linux/build_linux.sh 1.0.0
```

В папке `dist` появятся `gotrainer_1.0.0_amd64.deb` и `GoTrainer-1.0.0-x86_64.AppImage`.

## Сила компьютера и скорость

На процессоре разбор партии 9×9 занимает около минуты, 19×19 — несколько минут.
«Глубина разбора партии» в настройках: меньше — быстрее, больше — точнее (по умолчанию 100).
Нейросеть по умолчанию — `g170e-b20c256x2` из официальных релизов KataGo. Более новые и сильные
сети можно скачать с https://katagotraining.org/networks/ и положить файл `*.bin.gz` в папку
`katago` — игра возьмёт самый большой файл.

## Как устроен код

| Файл | Что делает |
|---|---|
| `gogame/board.py` | Правила: доска, захват, ко, самоубийство, история партии, фора |
| `gogame/scoring.py` | Подсчёт по китайским и японским правилам, мёртвые камни |
| `gogame/explain.py` | Объяснения ходов: тактика (атари, лестница, глаза…) + оценка ИИ |
| `gogame/engine/katago.py` | Работа с KataGo через JSON-протокол анализа |
| `gogame/engine/bot.py` | Уровни силы бота |
| `gogame/engine/simple_bot.py` | Встроенный бот без KataGo |
| `gogame/engine/download.py` | Скачивание KataGo и нейросети |
| `gogame/problems/problems.json` | Задачи (собираются скриптом `tools/build_problems.py`) |
| `gogame/ui/` | Интерфейс на Qt (PySide6) |
| `gogame/problems/sgf_import.py` | Импорт задач из SGF-сборников (задачники и лекции wbaduk) |
| `gogame/problems/library.json.gz` | Библиотека задач (собирается `tools/build_library.py <папки с SGF>`) |
| `tools/translations/library_ru.json` | Русские переводы текстов библиотеки (оригинал → перевод); подхватываются при сборке |
| `tools/build_problems.py`, `tools/course_extra.py`, `tools/course_meta.py` | Описание курса задач |
| `tools/verify_problems.py`, `tools/check_course.py` | Проверка задач с помощью KataGo |
| `packaging/gotrainer.spec` | Сборка программы без Python (PyInstaller) для Windows и Linux |
| `packaging/linux/` | Сборка пакета .deb и AppImage, ярлык для меню |
| `packaging/make_icon.py` | Значок игры (`gogame/icon.png`, `packaging/icon.ico`) |

### Как добавить задачу

Откройте `tools/course_extra.py` (или `tools/build_problems.py` для первых уровней), скопируйте похожую задачу, нарисуйте доску символами
`X` (чёрные), `O` (белые), `.` (пусто), укажите правильные ходы с объяснениями и ошибки с ответом
соперника. Затем:

```bash
python tools/build_problems.py      # собрать problems.json
python tools/check_course.py 7-1    # проверить задачу через KataGo
```
